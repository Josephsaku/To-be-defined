# 待确认 · To be defined

支持单人及 2–3 人局域网联机的网页调查游戏。各自在电脑浏览器里查看旧论坛、标注平台和扫描店取件站，分享线索，解开登录与资料谜题，最后共同署名结案。

当前版本：50 个可读页面、20 张图片、3 种结局，每种都有独立背影照片和结局弹窗。可完整通关，仍在打磨剧情、难度与游戏时长。

## 启动主机：只做这 4 步

1. **主机安装 [Node.js LTS](https://nodejs.org/)**，版本须为 20 或更高。安装后重新打开终端。
2. **把仓库拉下来：**

   ```bash
   git clone https://github.com/Josephsaku/To-be-defined.git
   cd To-be-defined
   ```

3. **启动游戏：**

   ```bash
   npm start
   ```

   Windows 也可双击仓库里的 **`start.cmd`**。没有第三方依赖，**不用 `npm install`、不用构建，也不用配置 API Key**。图片已随仓库提供。

4. **打开网页并加入：**
   - **自己玩：**打开 **http://localhost:3031**，点击 **“单人开始”**，直接进入论坛。昵称可以留空。
   - **一起玩：**主机填写昵称，选择两人或三人，点击“创建联机房间”。
   - 朋友与主机连接同一个 Wi-Fi / 局域网，打开启动窗口显示的 **局域网地址**，例如 `http://192.168.1.8:3031`。这个地址中的 IP 以主机显示为准。
   - 朋友输入房间码；人到齐后，房主点击“打开论坛”。

单人也能体验全部页面、标注、谜题与三个结局，回信由自己署名发送。已创建联机房间但只有自己时，可以点击“自己先玩”。

朋友只需要浏览器，不用下载仓库，也不用安装 Node.js。**朋友不要输入 `localhost`，那会指向朋友自己的电脑。**

游玩期间保持主机终端开着，主机不要休眠。结束时按 `Ctrl+C` 停止服务。Windows 第一次询问防火墙权限时，允许 Node.js 在当前的专用网络通信。

## 重新拉取、更新与存档

新克隆的目录直接执行 `npm start` 即可开始新游戏。

已有目录更新时，先停止主机，然后执行：

```bash
git pull --ff-only
npm start
```

存档自动保存在 **`data/rooms.json`**，已被 Git 忽略，不会上传到 GitHub，也不会随新克隆下载。想保留原进度，停止主机后备份整个 `data/` 文件夹，再复制到新克隆的仓库根目录。

恢复身份时使用原来的浏览器和地址；不同设备、浏览器以及 `localhost` / 局域网 IP 不共用登录身份。网页刷新可以恢复房间，已结案的房间保持归档状态。

## 连不上时

| 现象 | 处理 |
| --- | --- |
| 找不到 `node` 或 `npm` | 安装 Node.js LTS 后重开终端。 |
| 主机自己打不开 | 查看启动窗口是否报错；确认服务仍在运行，端口与网址一致。 |
| 主机能开，朋友打不开 | 确认同一局域网、使用主机的局域网 IP；检查主机防火墙和路由器的访客隔离。 |
| 窗口显示多个局域网地址 | 优先使用 Wi-Fi / 物理以太网对应的地址；Windows 可用 `ipconfig` 查看当前网卡的 IPv4。 |
| 3031 已被占用 | 关闭另一份游戏主机，或按下面的方法换端口。 |

PowerShell 更换端口：

```powershell
$env:PORT = "3032"
npm start
```

此时主机使用 `http://localhost:3032`，朋友也使用同一个新端口。macOS / Linux 可用 `PORT=3032 npm start`。

这是需要 Node.js 服务端的局域网游戏，GitHub 用于存放代码；**GitHub Pages 不能直接运行联机服务端**。

## 目录与开发

```text
server.mjs          房间、联机事件、权限、解谜与存档
content.mjs         主线页面与证据
extra-content.mjs   各资料的发现入口
story-copy.mjs      当前剧情与扫描店业务资料
forum-conversations.mjs  论坛正文、回帖与签名
dark-case.mjs       账户谜题、内部资料和剧情规则
annotations.mjs    标注校验
public/            网页、样式、20张游戏图片
art/               图片母版、生成提示词与生成记录（含剧透）
docs/              玩法和当前完整剧情（含剧透）
tests/             独立临时存档上的自动检查
data/              运行后生成的本地存档，不提交
```

执行 `npm test` 检查单人和多人流程、三个结局、账户谜题、标注、图片及页面入口。测试使用独立临时目录和随机端口，不改动正在玩的存档。
