# 网站关系与资料来路（剧透）

## 为什么能从论坛查到扫描店

长桥图文是文化路十八号的小店，老周平时就在散工之家发营业消息，坛里的修电脑师傅也会去打印、借扫描仪、还光盘。取件网址由他在营业帖里留下。罗启的结算截图只提到店名和回执，让玩家回论坛找老周；不再直接塞一个档案入口。

## 罗启到底去做什么

罗启接了分图网的旧照片核对任务，被反复退单，19.60元结不了。网页参考图和他存下来的预览还在变。他要求看原图，客服取得送件单位同意，让长桥图文向他开放三袋扫描件和实物核对。

店面仍在文化路，批量资料存放在南郊货站西侧租用库房。他预约9月21日晚上顺路去核对纸质照片。没有罗启去复印一封信的情节。

罗启白天登记姐姐为备用代领人：如需把三袋材料借出来复查，她在附近，可以帮忙拿。之后他发现门后的东西在模仿自己，想取消代领。普通的“纸质原件，3袋”已经变成了“罗启，1人”。

## 时间线

- 2004、2008、2010年：医院、学校、货站各自拍摄工作照片。
- 2010年12月：第一轮图片整理发生异常，留下旧投诉；平台后来又把这批照片放回任务。
- 2011年8月14日：长桥图文重新扫描原件，保留三家单位的袋子与纸张顺序。
- 9月19—20日：分图网把多数标注当成参考答案，三处地点被混为一处，图中逐渐出现人。
- 9月21日10:33：客服安排罗启核对原件。10:42，他填姐姐为备用代领人。
- 20:46：罗启到库房。20:57，他通过手机工单说明纸上没人。
- 21:08：平台出现无名改动。21:17，罗启报告门后出现学校和医院的景象。
- 23:36：罗启要求别让姐姐来拿。23:37，订单待领内容变成“罗启，1人”。23:38，他补传最后的照片。
- 9月23日：姐姐找到玩家，玩家沿网页留下的痕迹还原经过。

## 异常如何发生

游戏中的异常会沿着被反复确认的图像与文字关系扩展。把三处地点反复归为一处，门就开始互通；把门边的人认成罗启，代领记录就开始催姐姐来接。扫描店与平台原本只有正常的委托业务联系。

这是本故事的超自然规则。玩家从原片、改动记录、罗启描述、订单前后版本和上次投诉中交叉验证；普通店铺页面不会主动解释怪物规则。

结局要求两件事同时完成：恢复照片的来源、停用错误参考；取消已经被篡改的代领申请。前者让罗启有路出来，后者阻止门边的东西被当作他领走。
