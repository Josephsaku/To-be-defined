# 待确认

2011年9月23日。罗启前天晚上出门后一直没回来。他白天修电脑，晚上在分图网接标图的活。他姐姐罗岚找到了他留在电脑上的论坛和结算截图，想知道他去了哪里。

从散工之家的《标旧照片那单，有人拿到钱了吗？》开始。帖子里的网址和聊天内容会把调查带向分图网和长桥图文。

## 三个网站

- 散工之家：本地兼职论坛。讨薪、修电脑、二手交易，还有附近小店发的营业消息。
- 分图网：接活的平台。作业、结算、客服工单和罗启从手机补传的说明留在这里。
- 长桥图文：文化路的扫描店。通过订单查扫描文件、原件预约和代领记录。网址在老周的论坛帖子里。

## 开始

首页点“单人开始”即可独自游玩，所有资料与结局均可完成。两人或三人游玩时各自浏览，订单解锁、收藏、便笺和关键进度共享。收藏夹也保留网页来路，可以跟上同伴查到的资料。

关键画面会等在线玩家就绪后同步出现。入场处可选择减弱突然出现的画面。结局在独立弹窗展示，关闭后仍可回看网页；失败后可以回到最后一步。

目前有50个页面、21篇论坛帖子、20张游戏图片和3种结局。目标时长约60分钟，实际时长仍需真人试玩校准。
